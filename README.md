# ODOT Digital Delivery Toolkit Library

Central repository for official Oklahoma Department of Transportation (ODOT) Digital Delivery standards, guidelines, and supporting documents.

This library serves as the published source for Digital Delivery guidance used across ODOT projects and the Common Data Environment (ProjectWise).

## Current Documents

| Document | Version | Location |
|----------|---------|----------|
| Digital Delivery Guidelines | 1.1 | [`Published/guidelines/`](Published/guidelines/) |
| Digital Delivery Modeling Standards | 1.0 | [`Published/modeling-standards/`](Published/modeling-standards/) |
| CADD Standards | 1.0 | [`Published/cadd-standards/`](Published/cadd-standards/) |
| ProjectWise User Guide | 1.0 | [`Published/projectwise/`](Published/projectwise/) |
| Digital Delivery Glossary | 1.0 | [`Published/glossary/`](Published/glossary/) |

All documents are 508-compliant PDFs.

## Usage

Download the current documents directly from the `published/` folders, or clone the repository to keep a local copy.

Large binary files (PDF, DOC, DOCX) are stored using Git LFS.
